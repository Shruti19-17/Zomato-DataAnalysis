# 🍽️ Zomato Data Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing Zomato customer and restaurant data using Python. The objective is to perform Exploratory Data Analysis (EDA), identify customer ordering patterns, understand restaurant preferences, and generate meaningful business insights through data visualization.

The analysis explores restaurant types, customer votes, ratings, spending behavior, online and offline ordering patterns, and restaurant categories receiving offline orders.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze the types of restaurants customers prefer.
* Identify the number of customer votes received by each restaurant type.
* Understand the distribution of restaurant ratings.
* Analyze the average spending of couples on online food orders.
* Compare ratings between online and offline orders.
* Identify restaurant types receiving more offline orders.
* Generate actionable insights from customer and restaurant data.

---

## ❓ Business Questions

The project answers the following questions:

1. What type of restaurant do the majority of customers order from?
2. How many votes has each type of restaurant received from customers?
3. What ratings have the majority of restaurants received?
4. What is the average spending of couples on each online order?
5. Which mode — online or offline — has received the maximum rating?
6. Which type of restaurant received more offline orders?

These questions form the core analytical requirements of the project.

## 🔍 Analysis Process

### 1. Data Collection

The project uses a Zomato customer/restaurant dataset containing information related to restaurant types, votes, ratings, customer spending, and ordering modes.

### 2. Data Cleaning

The dataset was inspected and prepared for analysis by:

* Checking the dataset structure
* Inspecting data types
* Identifying missing values
* Cleaning inconsistent values
* Preparing categorical variables for analysis
* Converting relevant columns into appropriate formats

### 3. Exploratory Data Analysis

EDA was performed to understand:

* Restaurant popularity
* Customer voting behavior
* Rating distribution
* Spending patterns
* Online vs. offline ordering
* Restaurant-type preferences

### 4. Data Visualization

Visualizations were created using Matplotlib and Seaborn to make the findings easier to understand and communicate.

---

## 📊 Key Analysis Areas

### Restaurant Type

The analysis identifies which restaurant category is most frequently selected by customers.

### Customer Votes

Customer votes are analyzed across restaurant types to understand customer engagement and popularity.

### Restaurant Ratings

The distribution of ratings is analyzed to identify the rating range received by the majority of restaurants.

### Customer Spending

The project analyzes the average amount spent per order by couples who primarily order food online.

### Online vs Offline

Online and offline ordering modes are compared based on their average ratings.

### Offline Orders

Restaurant types are analyzed to identify which categories receive a higher proportion of offline orders. This can help Zomato design targeted promotional offers.
